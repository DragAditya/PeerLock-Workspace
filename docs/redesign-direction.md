# Peerlock Complete Redesign Direction

The redesign will use an original **private editorial workspace** direction. It takes high-level lessons from the supplied references rather than copying their layouts, branding, copy, or visual assets. The aim is to make Peerlock feel less like a conventional encrypted SaaS dashboard and more like a considered digital product for people doing serious collaborative writing.

The new system will combine three principles. First, it will use strong editorial hierarchy and deliberate content pacing: oversized type only where it establishes a page’s purpose, compact utility labels for system state, and more breathing room around the work itself. Second, it will introduce a more assertive signal language—precise contrast, a purposeful cobalt-orchid accent, and clear moments of visual intensity—without sacrificing a calm, readable writing environment. Third, the working interface will use a functional neo-Swiss type system: a clean sans for reading and interaction, plus a disciplined mono treatment for encryption, room, persistence, and CRDT status.

Peerlock’s distinctive motif will be the **private relay**: small linked points, fragment-like lines, offset grid marks, and a user’s cursor signal. This visual vocabulary will recur across onboarding, the vault, the editor, settings, and academic materials. It reinforces the product’s technical premise—device-owned replicas connected to peers—without pretending there is a central cloud workspace.

The redesign will preserve dark-first accessibility and local-first privacy claims. Motion will be short, intentional, and limited to state transitions, panel movement, and navigation feedback. It will respect reduced-motion preferences, avoid animation on high-frequency editing interactions, and keep all document intelligence inside the browser.

## Reference observations

Maria João Abrantes’ portfolio demonstrates clear product-focused hierarchy, curated case-study pacing, and restrained dark presentation. Hue&Cry demonstrates the value of expressive scale, forceful contrast, and an interactive brand device. Vercel’s Geist presentation reinforces a precise, minimal typographic system with distinct sans and mono roles. Peerlock will transform these general lessons into its own privacy-first product expression rather than reproducing any protected reference content or visual expression.
