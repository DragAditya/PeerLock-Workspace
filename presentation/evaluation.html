INTERPRETATION /
The project demonstrates functional local-first collaboration; it does not fabricate latency, throughput, or scalability benchmarks.

Trade-offs and future extensions

Peer-mesh cost

Every participant contributes connection and bandwidth work. This makes unrestricted room size unsuitable for the current browser mesh model.

Membership limitation

Without a trusted central membership authority, the system can display and warn about the ten-peer scope but cannot provide global revocation or hard central admission control.

Endpoint limitation

Local browser persistence protects against application-server storage, not against an unlocked device, compromised browser profile, or intentionally shared room secret.

Future work

Self-hosted signaling, key rotation, encrypted user-chosen backup, access revocation, attachment support, and measured peer-churn experiments.
