01 / Problem framing

Why a peer-first editor?

P2P WORKSPACE · 02

Conventional trust model

Every edit can be routed through a central document service.

That service can become the ordering point, storage location, and processing boundary for the document—even when the collaborators simply want to write together.

BROWSER ACENTRAL
DOCUMENT SERVICEBROWSER B

Project objective

Keep the document in participant browsers and synchronize replicas directly.

The system narrows infrastructure to connection establishment. It does not claim that signaling disappears; it ensures that document content is outside the application-server data path.
