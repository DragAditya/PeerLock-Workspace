INVITE BOUNDARY /
A room uses a short code plus a random secret. The secret lives in the URL fragment, which is not included in the page request to the application host.

What is protected — and what remains visible

AREABOUNDARY
Document contentHeld in participant browsers and replicated directly between peers; not stored by this application server.
Signaling trafficUsed only to establish peer connectivity; the room secret is supplied to protect sensitive provider communication.
Network metadataConnection timing, IP-level details, and STUN/TURN-related metadata may remain visible to relevant network infrastructure.
EndpointsAn unlocked browser profile, compromised device, or shared invite secret can expose a participant’s local document.

HONEST CLAIM /
This is a privacy-first content boundary, not a claim of anonymity or absolute endpoint security.
