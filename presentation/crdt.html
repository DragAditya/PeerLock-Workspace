03 / Replication model

CRDT theory: conflict-free collaboration

P2P WORKSPACE · 04

Core idea

Each browser may edit its own replica without waiting for a central ordering service.

Yjs represents document changes as CRDT updates. When replicas meet again, those updates can be exchanged and merged in a deterministic way for ordinary collaborative text operations.

CRDT /
A conflict-free replicated data type is designed so independently modified replicas can converge after synchronization.

STEP 01

Independent replicas

Two browsers begin with the same shared document state.

Peer A: “Local first editor”
Peer B: “Local editor workspace”

STEP 02

Mergeable updates

Each edit becomes an update that is retained locally, including during disconnection.

A inserts “first”
+ update α
B inserts “workspace”
+ update β

STEP 03

Convergent state

When peers reconnect, updates are exchanged and every reachable replica converges.
